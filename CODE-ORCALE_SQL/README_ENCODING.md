# Nhắc Nhở Mã Hóa CODE-ORCALE_SQL

- Lưu `CODE.SQL` bằng `UTF-8` không BOM.
- Không copy nội dung qua công cụ làm mất dấu hoặc sinh mojibake.
- Nếu thấy chữ tiếng Việt biến thành chuỗi lỗi như `KHÃ...`, `ngÃ...`, `HÃ...` thì cần kiểm tra lại encoding trước khi lưu.
- Sau khi chỉnh tiếng Việt, nên rà lại các chuỗi trong dấu nháy đơn, comment, và các mã mẫu như `HĐ-TD`, `02A/HĐTD`.
